# Sistema de Venda de Passagens de Ônibus

Sistema de venda de passagens de ônibus com recurso de persistência, ou seja, os dados permanecem mesmo após encerramento do programa.
Exercício proposto como parte da avaliação da disciplina de Linguagem de Programação II.

## Recursos:
- Modularização de código (divisão de de ações via funções);
- Persistência de dados via arquivos (dados permanecem mesmo após encerramento do programa);
- Uso de funções de leitura e escrita binária.
